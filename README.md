# Quality & Compliance Analytics Portfolio

**Live site:** https://sannidhi-analytics.github.io/portfolio/

Applied analysis of regulatory and quality-systems data, spanning pharmaceutical GMP and UK financial services compliance. Built by Sannidhi Shetty — Quality Assurance professional with GMP manufacturing experience and an MSc in Business Analytics.

The premise of this portfolio is that quality functions generate a great deal of data — deviations, closure times, audit findings, recall reasons, enforcement actions — and most of it gets reported rather than analysed. Each project here takes a regulatory dataset and asks what it actually shows.

---

## Projects

### 1. GMP Deviation & CAPA Performance Dashboard
An interactive quality management dashboard covering 240 deviations across 24 months and four departments. Tracks closure performance, root cause concentration, and CAPA effectiveness.

Key findings: closure time improved 35% across the period (30.0 → 19.5 days); documentation errors are the largest single root cause at 23.8%; deviations with a CAPA raised recurred at 4.6% against 12.4% for those without.

Data: synthetic — see [Data sources](#data-sources) below.

### 2. What Actually Causes Drug Recalls
Analysis of 17,816 FDA drug enforcement records, with 3,000 recent recalls categorised by root cause from free-text recall reasons.

Key findings: CGMP deviations (36.6%) and contamination (34.1%) together account for 71% of recalls; 99.6% of recalls are firm-initiated, with only 29 FDA-mandated across the entire dataset; Class I recalls fell from 64 in 2021 to 22 in 2025.

Data: live, from the openFDA Drug Enforcement API.

### 3. Where UK Financial Regulation Bites
Every FCA enforcement fine published across 2023, 2024 and 2025 — 60 actions totalling £353.6m — analysed by breach theme, sector, and firm-versus-individual split.

Key findings: financial crime systems and controls failures account for 43% of all penalty value from 17% of actions; firms absorbed 95.5% of fine value while individuals accounted for 29 of the 60 actions; unsuitable pension transfer advice generated more separate actions than any other category.

Data: transcribed from the FCA's published annual fines pages.

### 4. Quality Assurance Case Studies
Three worked examples from GMP practice in situation–action–result form: reducing deviation resolution time by 30%, maintaining zero major audit findings through continuous change control discipline, and holding compliance across 25+ weekly quality cases without impacting production schedules.

Details are generalised to protect employer confidentiality.

## Data sources

| Dataset | Source | Type |
|---|---|---|
| `data/fda_summary.json` | [openFDA Drug Enforcement API](https://open.fda.gov/apis/drug/enforcement/) | Real — public FDA data |
| `data/fca_fines.csv` / `.json` | [FCA published fines](https://www.fca.org.uk/news/news-stories/2025-fines) (2023–2025) | Real — public regulatory data |
| `data/deviations.json` | Generated by `scripts/generate_data.py` | Synthetic |

**On the synthetic dataset.** The deviation records are generated, not drawn from any employer's quality system. This is deliberate: GMP deviation data is confidential, and exporting it would be a compliance failure in itself. The generator models a realistic severity mix, department distribution, closure-time improvement trend, and recurrence probability conditioned on whether a CAPA was raised — so the analysis demonstrates method against data with credible structure. It runs on a fixed random seed, so the dataset is exactly reproducible.

**On validation.** The FCA dataset is verified by reconciling computed annual totals against the regulator's own published figures. `scripts/analyse_fca.py` prints this check on every run:

```
2023: computed £   53,354,600 | published £   53,354,600 | MATCH
2024: computed £  176,045,385 | published £  176,045,385 | MATCH
2025: computed £  124,221,367 | published £  124,221,367 | MATCH
```

An exact reconciliation across all three years confirms the dataset is complete rather than a partial sample.

**Known limitations.** FDA recall reasons are free text, so root cause categorisation uses regular expression pattern matching in priority order; 6.1% of records match no pattern and are grouped as "Other". FCA breach themes were assigned by reading each Final Notice summary, which is judgement-based — another analyst might group some borderline cases differently. openFDA records are published as enforcement reports conclude, so 2025 and 2026 recall counts understate eventual totals and are marked provisional in the charts.

## Reproducing the analysis

No dependencies beyond the Python standard library.

```bash
python scripts/generate_data.py   # rebuild the synthetic deviation dataset
python scripts/fetch_fda.py       # re-fetch live data from the openFDA API
python scripts/analyse_fca.py     # validate and summarise the FCA fines
```

`fetch_fda.py` queries the live API, so recall figures refresh on each run. `generate_data.py` is seeded and will reproduce the committed dataset exactly.

To run the site locally, serve it over HTTP — the pages load data via `fetch()`, which browsers block on `file://` URLs:

```bash
python -m http.server 8000
```
